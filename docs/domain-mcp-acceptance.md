# Native business MCP acceptance

The domain acceptance suite exercises the JSON-RPC `lark_execute` handler,
actual dispatcher, precompiled argument schemas, automatic account selection,
and resumable workflows inside workerd. State uses encrypted Durable Object
SQLite and private R2 spill under the shared 2 GB quota. Lark API and binary
transfer ports return deterministic fixtures; no external account is accessed
and no real upstream write occurs.

Monthly task queries preserve explicit false, inclusive UTC date boundaries,
pagination after filtered pages, and large results without requiring artifact
permission. Document creation accepts Markdown and preserves asynchronous
creation without duplicate writes. Drive import stages a private artifact;
export resolves a Wiki node and checkpoints a ticket before polling or saving
an output artifact. A virtual workflow clock proves that early resumes do not
poll upstream and that the requested delay permits progress afterward.

Wiki reads and native Markdown fetches retain their business projections and
private artifact ownership. OKR cycle filtering preserves the upstream cursor.
These are representative end-to-end fixtures, not exhaustive shortcut coverage
or proof of live Dots authorization and service compatibility.
