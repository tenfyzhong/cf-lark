# Visual identity

The cf-lark favicon uses an original bird illustration to suggest flight and
communication. It must not reproduce or trace the Feishu/Lark logo, its silhouette,
its folded ribbon construction, or its blue/green brand palette. The design uses
a rounded warm-white bird, a single broad rising wing, an amber beak and a deep
aubergine background. No official logo assets are incorporated.

This is independent project artwork, not an official Feishu/Lark brand mark.
Visual differentiation is a design requirement, not a legal clearance guarantee.

The browser icon is served as a local PNG from the Vite public directory and
referenced explicitly in the HTML head. The artwork must remain legible at
favicon size and require no third-party image requests.
